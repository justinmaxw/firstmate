GEMINI_API_KEY stripped at the REAL agy child, on a worker host that carries the key
===================================================================================

This reproduces the exact gap the review round flagged: fm-spawn's caller-side
refusal reads its OWN process environment, but the pane is created by a long-lived
tmux/herdr daemon whose environment fm-spawn never saw. Only the 'env -u
GEMINI_API_KEY' prefix on the launch template can keep the run on the Google AI Pro
subscription instead of pay-as-you-go API billing.
